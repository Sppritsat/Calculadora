# 📊 Calculadora Financiera de Proyectos

Una herramienta web completa para el análisis y proyección financiera de proyectos empresariales. Desarrollada como proyecto académico para facilitar el cálculo de presupuestos, flujos de efectivo y estados financieros.

## 🎯 Descripción

Esta calculadora financiera permite a estudiantes y emprendedores realizar análisis financieros completos de proyectos, incluyendo:

- **Análisis de Mercado**: Cálculo de mercado meta y penetración
- **Proyección de Ventas**: Estimación de ventas futuras
- **Presupuestos**: Producción, materias primas, mano de obra
- **Estados Financieros**: Estado de resultados, balance general, flujo de efectivo
- **Análisis de Inversiones**: Cálculo de depreciaciones y ROI

## 🚀 Inicio Rápido

### Opción 1: Abrir directamente (Recomendado)
1. Descarga o clona este repositorio
2. Abre el archivo `Calculadora_financiera/index.html` en tu navegador
3. ¡Comienza a usar la calculadora!

### Opción 2: Servidor local
```bash
# Clona el repositorio
git clone https://github.com/Sppritsat/Calculadora.git

# Navega al directorio
cd Calculadora

# Abre con un servidor local (ejemplo con Python)
python -m http.server 8000

# Abre en tu navegador: http://localhost:8000/Calculadora_financiera/
```

## 📝 Características Principales

### Pestañas de Análisis

1. **Mercado Meta**: Define tu mercado objetivo y calcula la penetración
2. **Proyección de Ventas**: Proyecta ventas con factores de sensibilidad
3. **Ingresos**: Calcula presupuesto de ventas con precios variables
4. **Condiciones Comerciales**: Define plazos de cobro y pago
5. **Inversiones**: Registra activos y calcula depreciaciones
6. **Producción**: Planifica unidades a producir
7. **Materia Prima**: Calcula necesidades de materiales
8. **Compras MP**: Presupuesto de compras
9. **Valuación Inv.**: Valuación de inventarios
10. **Mano de Obra**: Costos de personal
11. **Gastos Indirectos**: Costos indirectos de fabricación
12. **Costo Vendido**: Costo de lo vendido
13. **Gastos Operación**: Gastos administrativos y de ventas
14. **Estado Resultados**: Estado de resultados proyectado
15. **Balance**: Balance general proyectado
16. **Flujo Efectivo**: Flujo de efectivo proyectado

### Funcionalidades Especiales

- 📊 **Exportar Datos**: Descarga tus análisis en formato JSON
- 🖨️ **Imprimir Reporte**: Genera reportes imprimibles
- 📱 **Responsive**: Funciona en dispositivos móviles y tablets
- 💾 **Datos Globales**: Los cálculos se sincronizan entre pestañas
